# garden-texts

Texts of «Учусь мыслить», the digital garden at [sanch.pet](https://sanch.pet): Markdown and media only. The site engine lives in [sanchpet/garden](https://github.com/sanchpet/garden) and pulls this repository at build time.

The garage door is open: texts are visible here from their first edit, before they are published, with the whole history. Links that point outside the published corpus are visible here too; the build strips them from the site.

- `posts/` — dated texts
- `evergreen/` — evergreen notes, revised over time
- `index.md` — the home page
